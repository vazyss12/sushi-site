САЙТ ДЛЯ СУШИ-ДОСТАВКИ "СУШИ ДОМ"
=====================================

СТРУКТУРА:
- index.html  — главная страница
- style.css   — все стили
- script.js   — логика (корзина, меню)

КАК ЗАПУСТИТЬ:
1. Откройте index.html в любом браузере (Chrome, Яндекс, Firefox)
2. Всё работает

КАК ИЗМЕНИТЬ:

1. ТЕКСТЫ:
   - Откройте index.html в блокноте
   - Найдите нужный текст и замените

2. ЦВЕТА:
   - Откройте style.css
   - В самом верху блок :root
   - Переменная --red: #ff3c5a — главный цвет
   - Поменяйте на свой

3. МЕНЮ РОЛЛОВ:
   - Откройте script.js
   - Вверху массив sushiData
   - Меняйте название, описание, цену

4. ФОРМА ЗАКАЗА:
   - Сейчас при оформлении выскакивает alert
   - Чтобы заявки приходили на почту, подключите Web3Forms
   - Инструкция: web3forms.com

КАК ЗАЛИТЬ НА ХОСТИНГ:
1. Зарегистрируйтесь на любом хостинге (Beget, Timeweb, reg.ru)
2. Загрузите 3 файла через FTP или панель
3. Готово
